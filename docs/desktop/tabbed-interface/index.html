Desktop: Tabbed Interface 💻 Desktop

Real browser-style tabs across one or many windows. Real keyboard shortcuts.

Desktop is in active development. See tabssh/desktop for current status — some shortcuts below are wired, others are planned.

🪟 Multi-Window Tabs

  • Each window has its own tab strip.
  • Ctrl+N opens a new window; useful for separating prod / staging visually onto different displays.
  • Tabs can be dragged between windows (planned).
  • Closing the last tab in a window doesn't kill TabSSH — the window collapses to the tray.

⌨️ Tab Shortcuts

  • Ctrl+T — new tab (opens Quick Connect dialog)
  • Ctrl+W — close current tab
  • Ctrl+Tab / Ctrl+Shift+Tab — cycle forward / backward
  • Ctrl+1..9 — jump to tab N
  • Ctrl+Shift+T — reopen the last closed tab

🎯 Command Palette & Switchers

  • Ctrl+K — command palette: fuzzy-search across saved hosts (from ~/.ssh/config), snippets, identities, workspaces. Hit Enter to launch.
  • Ctrl+J — quick switcher: only currently-open tabs.
  • Ctrl+R — history palette: recent connections with timestamps.
  • Same UX as the mobile palettes, with hardware-keyboard ergonomics.

🧷 Workspaces

  • Save the current set of open tabs as a named workspace.
  • Restore in one click — connections fan out with a small inter-host stagger so you don't slam every host at once.
  • Workspaces shared with mobile via the encrypted sync blob (when sync ships on desktop).

📡 Broadcast Input & Cluster Commands

  • Pick multiple tabs, type once, send to all.
  • Cluster commands: pick hosts from ~/.ssh/config, run a single command, get live result streaming.

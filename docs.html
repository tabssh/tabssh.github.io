Technical Details

What's New in TabSSH

Recent waves shipped (post-v1.0.0 baseline)

  • Wave 1: Per-connection env vars, SSH agent forwarding, remote file editor in SFTP, chmod editing, SCP fallback, find/search in scrollback, bulk import (CSV/JSON/PuTTY)
  • Wave 2: OpenSSH user certificate auth, Telnet protocol, GUI theme editor, Workspaces (named tab groups), command palette (Ctrl+K), quick switcher (Ctrl+J), broadcast input, split-view multi-pane, history palette (Ctrl+R)
  • Wave 3: Per-host color tags, PIN-code app lock, background tunnels, browser-open URL handling, what's-new screen
  • Wave 4: 24-bit color rendering, foldable book-mode + tablet sw720dp layouts, cluster command live result streaming
  • Wave 5: Cloud host import (DigitalOcean / Hetzner / Linode / Vultr), 3-way merge with conflict UI for sync
  • Wave 6: SSH config export (round-trip), bulk delete + import wizards
  • Wave 7: VM serial console via hypervisor API (no VM network needed), full Xen Orchestra REST + WebSocket integration
  • Wave 9.2: Mosh native binaries cross-compiled per Android ABI, monthly auto-refresh workflow, embedded terminfo fallbacks
  • Hardening: ANR watchdog + crash reporter (debug builds auto-on, release opt-in), centralised host-key dialog, working theme switching, 23 built-in themes, build-aware debug logging

💻 Desktop development status

The desktop client is in active development. Working today: SSH connect/auth and terminal I/O via russh + alacritty_terminal. In progress / planned: SFTP, port forwarding, themes, OS keychain integration, hypervisor support, sync.

🚀 Getting Started

Ready to contribute? Here's how to get involved:

  1. Explore the App: Download and use TabSSH to understand its features
  2. Pick a repo: mobile lives in tabssh/android, desktop in tabssh/desktop. Each repo has its own issue tracker, README, and contribution notes.
  3. Read the Code: Browse the source on the repo to get familiar with the layout
  4. Join Discussions: Participate in community discussions on the repo
  5. Submit Pull Request: Create a branch, make changes, and submit a PR
